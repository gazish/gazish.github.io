Decision analysis tool: weighted sum, AHP and sensitivity

Compare options on several criteria, set the weights directly or derive them from pairwise comparisons, and see how stable the ranking is when the weights and the scores change. Everything runs in your browser.

Illustrative example data. The five climate adaptation measures and all numbers in the table are made up for this demo. They are not real municipal data and not results from my thesis. Edit the table or replace it with your own decision.

1Options and criteria

Each row is an option, each column a criterion. Set whether higher or lower values are better, and how uncertain the values are. All cells are editable.

Scores use a linear value scale per criterion: the worst value in the table scores 0 and the best scores 100.

2Weights

Weighting method

Give each criterion points from 0 to 100. The weights are the points divided by their total.

For each pair, move the slider towards the criterion that matters more, on Saaty's 1 to 9 scale. The weights are the principal eigenvector of the comparison matrix.

3Ranking

    4Sensitivity to the weights

    5Uncertainty: Monte Carlo simulation

    Draws 5,000 scenarios. In each, the weights and (optionally) the values in the table vary at random, and the options are ranked again. This shows how robust the ranking is overall, not one weight at a time.

    Problem

    Decisions like which climate adaptation measure to fund first involve criteria that pull in different directions: cost, risk reduction, side benefits, time. People also disagree on how much each criterion should count. A single ranked list hides how much the answer depends on those choices. I wanted a tool that shows the ranking and, next to it, how easily it changes.

    Approach

    1. ScoreEach criterion gets a linear value scale from the worst to the best value in the table, so costs and scores in different units become comparable.
    2. WeightEither direct points, or AHP: pairwise judgements on Saaty's 1 to 9 scale, weights from the principal eigenvector, and a consistency ratio with a pointer to the least consistent judgement.
    3. RankWeighted sum of the values, shown as stacked contributions so you can see why an option wins.
    4. Test one weight at a timeFor each criterion, the exact weight range in which the top option stays first, found by solving the linear score equations rather than by trial and error.
    5. Test everything at onceA Monte Carlo simulation that varies all weights (Dirichlet distribution) and the table values, then reports how often each option gets each rank and its rank interval.

    My MSc thesis used related ideas (weighted criteria, stakeholder weights, uncertainty ratings and best- and worst-case rank intervals) for local climate hazards. This tool is a separate, general demo: it does not reproduce the thesis model or its results. Read about the thesis.

    Tools

    Plain JavaScript modules and SVG, with no chart or maths library. The maths sits in one module (mcda.js) with no browser code, covered by 11 unit tests run with Node's built-in test runner. One test checks the AHP weights, λmax and consistency ratio against the standard 3 x 3 textbook example. Another checks the stability intervals against a brute-force search.

    Result

    With the example data and the default weights, stormwater retention ponds rank first with 63.8 points, 8 ahead of green roofs. The ranking is most sensitive to the weight on flood risk reduction: lowering it from 30% to about 22% puts street trees and pocket parks first. In the Monte Carlo run with moderate weight changes and uncertain values, the ponds come first in about 70% of scenarios. Those are statements a decision maker can check against their own priorities, which a bare ranking does not allow.

    What I would do next

    • Uncertainty ratings per cell rather than per criterion, as in my thesis.
    • Swing weighting as a third method, since weights in an additive model depend on the ranges in the table.
    • Several stakeholders: collect AHP judgements from each and combine them with the geometric mean, or show the spread between them.
    • Non-linear value functions for criteria where the first improvements matter most.
    Method notes: formulas, assumptions and limitations

    Additive value model

    The overall value of option a is V(a) = Σj wj vj(xaj) with wj ≥ 0 and Σ wj = 1. Each vj is linear on a local scale: 0 for the worst value in the table and 1 for the best. The model assumes the criteria are preferentially independent. Because the scales are local, the weights are trade-offs between the ranges in the table: if an option is added that widens a range, the weights should be reviewed.

    AHP weights and consistency

    Judgements aij on Saaty's scale form a reciprocal matrix (aji = 1 / aij). The weights are its principal right eigenvector, found by power iteration. Consistency: CI = (λmax − n) / (n − 1) and CR = CI / RI, with Saaty's random index RI = 0.58, 0.90, 1.12, 1.24 and 1.32 for n = 3 to 7. CR of 0.10 or less is the usual threshold. The least consistent judgement is the one with the largest |ln(aij wj / wi)|; the suggested replacement is the geometric mean of the indirect comparisons aik akj. AHP is used here only to elicit criterion weights. One known criticism applies: AHP asks about importance in general, while additive value weights depend on ranges, which is why swing weighting is on the list above.

    One-at-a-time sensitivity

    The weight of criterion j is set to t and the others are rescaled in proportion: wk(t) = wk (1 − t) / (1 − wj). Every score is then linear in t, so the interval in which the top option stays first is found exactly by solving one linear inequality per competing option.

    Monte Carlo rank analysis

    Weights are drawn from a Dirichlet distribution with parameters κ w, so their mean is the current weights and their spread shrinks as κ grows (κ = 200, 50 or 10). "Any weights at all" draws uniformly from all possible weight vectors, as in SMAA-2 when no preference information is available. Table values move uniformly by up to ±5%, ±15% or ±30% of the criterion's range in the table. The tool reports rank acceptability (the share of scenarios in which an option takes each rank) and rank intervals. It uses 5,000 draws with a fixed random seed, so results are reproducible.

    Limitations

    • Linear value functions and independent, uniform perturbations. Real uncertainties are often correlated.
    • Local scales: results can change when options are added or removed.
    • A weighted sum lets a strong score on one criterion make up for a weak one. If some criteria are must-haves, screen options first.
