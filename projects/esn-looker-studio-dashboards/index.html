Volunteer work · Erasmus Student Network · May 2025 to Apr 2026

From a manual monthly report to Looker Studio dashboards

As a volunteer data analyst, working remotely, I replaced a manual monthly reporting process with three Looker Studio dashboards.

Role
Data Analyst (volunteer), remote
Where
Erasmus Student Network (ESN)
When
May 2025 to Apr 2026
Scale
About 5,000 to 6,000 activities a month; 519 local sections in 45 countries
Tools
Looker Studio

The dashboards and ESN's data are internal, so this page describes the work without showing them.

Problem

Monthly reporting on activities was compiled by hand, from data spread across several sources.

Approach

  1. Clean and consolidate the dataI cleaned the data from several sources and brought it together into one consistent dataset.
  2. Build three dashboardsI built three Looker Studio dashboards on that dataset, so the monthly numbers no longer had to be compiled by hand.
  3. Document for handoverI wrote down the dashboard logic and the data definitions, so the next volunteer can maintain and extend the dashboards.

Tools

Looker Studio for the dashboards.

Result

The monthly numbers are no longer compiled by hand. Three dashboards cover about 5,000 to 6,000 activities a month and are available to all 519 local sections in 45 countries.

What I would add

  • Ask sections which views they use and which questions they still cannot answer, then adjust the dashboards.
  • Add automatic checks on incoming activity data, such as missing fields and duplicates, before it reaches the dashboards.
  • Track dashboard usage to see which sections rely on them.
